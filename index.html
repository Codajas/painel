Exportar para o Free Claude Code

O Free Claude Code lê suas chaves de um arquivo .env na sua pasta de usuário. Siga os passos abaixo para aplicar as chaves deste painel no seu terminal.

C:\Users\SeuUsuario\.fcc\.env

Dica: Baixe o arquivo .env e o script .bat na mesma pasta (ex: Downloads) e clique duas vezes no .bat. Ele moverá a chave para a pasta correta automaticamente.

Envio via API Local

Se o servidor do FCC estiver rodando na sua máquina, o painel tenta enviar as chaves via HTTP para a porta 8082.

Sobre o Projeto

O Free Claude Code permite usar modelos de linguagem no terminal sem custos de API, roteando requisições.
